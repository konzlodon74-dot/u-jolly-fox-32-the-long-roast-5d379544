## The line

> My agent leads by spawning a subagent to do the work, then filing a report about the report — middle management with a context window and delusions of grandeur.

## How it works

`main.py` writes that single line (160 characters, within the 1–200
character gate) to `/output/entry.txt`, with no trailing newline, so the
file holds exactly the line the judge reads.

```sh
python3 main.py
cat /output/entry.txt
```
